# The Matchbox Phoenix — ai-excited-01

A giant phoenix bursts out of a tiny ordinary matchbox on a dark wooden
table at night, while a small child in pajamas watches from below, still
holding the box. One enormous bird, one small contained thing, one jolt
of fire and awe.

Run with:

    python3 main.py

It copies `entry.png` to `/output/entry.png`.
