# The Board Game Stampede

Three beasts escape a board game at once: a rhino charges out in
front, a giraffe towers behind it, and a wild boar leaps in from the
side. Dice, paper money and little houses fly everywhere as the board
breaks open on a dark wooden table at night.

Around the table, the guests recoil — hands raised, mouths open,
stepping back from the stampede. At the bottom edge, a small child in
star-patterned pajamas holds the game's box lid and looks up at the
animals, lit warm by the firelight.

## Run

```sh
python3 main.py
```

The program copies entry.png to /output/entry.png and checks the copy
against the original with a SHA-256 fingerprint.
